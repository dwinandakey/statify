# Skenario pengujian black-box: GLM Multivariate dan GLM Repeated Measures

- **Build yang diuji:** `skripsi-final-v2` (commit `d863de09`), dijalankan lokal dengan `npx next start -p 3001` (lihat `testing/RELEASE-NOTES.md` §v2.5).
- **Acuan kebutuhan:** Tabel 5 revisi; pemetaan ke kode ada di `pemetaan-kebutuhan.md`.
- **Status:** penyusunan saja. Kolom Hasil Pengujian dan Keterangan diisi saat eksekusi.
- **Salinan tabel:** `skenario-black-box.csv` (UTF-8 dengan BOM, dapat dibuka di Excel), kolom sama dengan Tabel 7 dan Tabel 8.

## Ketentuan umum

- **Langkah awal setiap skenario:** buka `http://localhost:3001/dashboard/data`, lalu impor berkas di kolom Data Uji lewat File → Import → CSV. Setiap skenario dimulai dari dialog yang sudah di-Reset, kecuali skenario yang menguji penyimpanan konfigurasi.
- **Asal data:**
  - `testing/glm-mv-reference/data/`, `testing/glm-rm-reference/data/`: dataset acuan validasi SPSS.
  - `testing/glm-web-worker/results/…/data/`: data eksperimen Web Worker.
  - `testing/black-box/data/`: dataset baru untuk skenario negatif, dibuat oleh `make_data.py`.
- **Hasil di halaman Result:** "Errors Logs" adalah tabel di halaman Result dengan kolom Context dan Message.
- **Toast:** setiap toast tampil dua kali di seluruh aplikasi, karena ada dua `<Toaster>` (bawaan, di luar GLM). Toast ganda bukan kegagalan skenario.
- **"Nilai sesuai SPSS (mvX/rm_X)":** konfigurasi yang sama sudah divalidasi terhadap keluaran SPSS 27 (`testing/glm-mv-reference/results/spss-validation/`, `testing/glm-rm-reference/`). Saat eksekusi, cukup dicocokkan beberapa nilai utama (misalnya Wilks' Lambda dan Sig.) dengan berkas keluaran SPSS tersebut.
- **Kolom Skenario Pengujian:** diawali "Positif:" (masukan valid, keluaran diharapkan) atau "Negatif:" (masukan tidak valid atau data bermasalah, pesan diharapkan).
