# Track C3 — Pengujian black-box menu Apply Model dan persistensi Naive Bayes (BB-29 sampai BB-36)

Dokumen ini adalah hasil Track C3 untuk skenario BB-29 s.d. BB-36 pada modul Text Analytics Statify. Kolom tabel mengikuti format prompt evaluasi. Kolom "Hasil yang diharapkan" adalah versi yang sudah diverifikasi terhadap kode sumber (bukan salinan tabel prompt); selisih terhadap tabel prompt dicatat pada bagian "Catatan penyesuaian".

## Cara membaca status

- Penanda `⟦jest:<berkas>::<nama tes>⟧` dan `⟦rust:<target>::<fungsi>⟧` diganti menjadi Lulus, Gagal, atau BELUM DIJALANKAN oleh `tools/apply_results.py` berdasarkan `logs/jest_*.json` dan `logs/rust_*.txt`.
- Tes Jest dijalankan di sandbox (VM Linux, `tools/run_jest_linux.sh`, ts-jest) dan seluruhnya lulus: 95 dari 95 tes pada 7 berkas (`logs/jest_C3_vm.json`, `logs/jest_C3_vm.txt`). Hasil ini bukan hasil perangkat uji skripsi; hasil final berasal dari `run_C3.ps1` di Windows (`logs/jest_C3_win.json`, konfigurasi Jest produksi).
- Komputasi BB-33 dan BB-35 pada tes Jest dijalankan oleh biner WASM Apply Model yang sudah dibangun dan dilacak git (`public/workers/Classify/ApplyModel/pkg`), dimuat lewat pengganti Worker; angka acuannya berasal dari oracle Python independen (`tools/c3_am_oracle.py`), bukan dari keluaran aplikasi.

2. **BB-29 (bukan model).** Tidak ada kode khusus untuk "bukan berkas JSON". Ekstensi selain `.json` dan isi yang bukan JSON sama-sama memberi `AM_E_PARSE` ("The model content could not be read as valid JSON."), sehingga untuk berkas `.txt` pesan itu kurang tepat sasaran (BUGS_C3.md, C3-02). Batas ukuran tepat 10 × 1024 × 1024 byte (10 MiB), sedangkan pesan menyebut "10 MB" (C3-03). Ekstensi diperiksa sebelum ukuran.
3. **BB-30 (Output Viewer).** Pesan "belum ada model" adalah peringatan (`AM_W_NO_RESULT_STORE_MODELS`) tanpa akhiran kode, bukan galat `AM_E_`. Hanya statistic "Export Model" dari Naive Bayes yang masuk daftar.
4. **BB-31 (Auto-map).** Pemetaan otomatis tidak memeriksa measure; ketidakcocokan measure baru terlihat setelah validasi (`AM_E_MAP_ROLE_MISMATCH`). Pemetaan juga dijalankan otomatis ketika model dimuat, jadi tombol "Auto-map by name" berguna terutama untuk menimpa pilihan manual atau setelah dataset berubah.
5. **BB-32 (pemetaan belum lengkap).** Tabel prompt menyiratkan semua pemetaan belum lengkap memblokir OK. Pada kode: variabel teks Raw dan fitur kategorikal/numerik yang belum terpetakan memblokir (`AM_E_MAP_RAW_TEXT_UNMAPPED`, `AM_E_MAP_UNMAPPED`), tetapi model Word-Vector dengan kolom `VEC_` yang tidak ditemukan TIDAK memblokir: kolom yang hilang diperlakukan 0 dan hanya muncul peringatan/info. Ini keputusan desain (AGENTS_V2), bukan cacat; dicatat sebagai penyimpangan dari tabel prompt.
6. **BB-33 (evaluasi).** Baris yang tidak diskor dan baris dengan Actual kosong atau kelas yang tidak dikenal model dikeluarkan dari evaluasi (dihitung di Case Processing Summary), bukan dihitung salah. Presisi/recall/F1 untuk kelas tanpa prediksi bernilai 0, bukan galat.
7. **BB-34 (nama bentrok).** Pada kode, bentrok dengan variabel yang sudah ada adalah penyesuaian otomatis disertai peringatan (`AM_W_NAME_ADJUSTED`), bukan galat. Hanya nama kustom yang kembar antar kolom hasil menjadi galat (`AM_E_NAME_DUPLICATE`). Pemeriksaan tak peka huruf besar/kecil.
8. **BB-35 (Output).** Tiga tabel yang disebut di prompt adalah subset: hasil selalu memuat juga Saved Variables, dan Evaluation Metrics, Cohen's Kappa, serta Confusion Matrix bila Actual target dipetakan.
9. **BB-36 (persistensi).** Persistensi berlaku untuk menu Naive Bayes dan terjadi hanya saat OK, bukan otomatis (BUGS_C3.md, C3-01). Penyimpanan ikut fingerprint variabel; dataset berbeda mereset form dan menghapus penyimpanan.
10. **Provenans WASM.** Tes BB-33/BB-35 memakai biner `pkg/wasm_bg.wasm` yang sudah ada di repositori. Biner ini dapat tertinggal dari sumber Rust; `cargo test --test thesis_blackbox_am` pada `run_C3.ps1` memeriksa sumber Rust yang berlaku. Nilai acuan kedua jalur identik (oracle Python), sehingga bila salah satunya gagal, itu menunjuk ketidaksinkronan biner dan sumber.
11. **Jest standar Windows.** Hasil VM memakai ts-jest; konfigurasi produksi (`frontend/jest.config.js` dengan `next/jest`) belum dijalankan oleh agen ini. Hasilnya akan masuk lewat `logs/jest_C3_win.json`.
